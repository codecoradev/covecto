# Covecto

Dual-engine image vectorization — **pixel-exact** for icons, **smooth curves** for art.

```bash
covecto input.png -o output.svg
```

## Two Engines, One Tool

| Engine | Best For |
|--------|----------|
| **PixelExact** | Icons, pixel art, screenshots |
| **Spline** | Photos, illustrations, artwork |
| **Auto** *(default)* | Let Covecto pick |
